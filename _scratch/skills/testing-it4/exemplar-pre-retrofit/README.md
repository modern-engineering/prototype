# Exemplar — annotated Go-team snippets

Read these files BEFORE writing tests. They are verbatim test code from the Go
standard library, chosen because the Go team's practice is the source of this
skill's doctrine: you imitate canon, not a synthetic demonstration. Nothing here
is agent-written or eval-derived; the only code allowed in this folder is
attributed snippets from the Go team's packages (standard library and
golang.org/x). The annotations after each snippet are ours and say what to
imitate and why.

One file per source package. Each names its source file and line ranges;
elisions are marked. Verify against the tree before trusting an edit.
